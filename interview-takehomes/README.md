# Northline take-home exercises

Small, self-contained take-home exercises grouped by track, then by stack, then by level. Each brief describes a product to build, the rules, requirements, deliverables, and how to submit.

Pick the one file that matches the role you were asked to try, read it, and build against it.

## How to submit

1. Build against the brief you were given. Respect the time box in the file.
2. Push to a public GitHub/GitLab repo, or send a zip.
3. Include a short `NOTES.md`: assumptions, tradeoffs, what you skipped, and how to run it.
4. Make sure a reviewer can run it from your instructions alone.

## Each brief has the same shape

1. Snapshot — stack, time box, product, how to submit
2. Candidate brief — what to build, rules, requirements, constraints, deliverables
3. Stretch — optional extras if you finish the core
